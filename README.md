## Project Description
The Electricity Bill Calculator is a C++ application that calculates electricity charges based on the number of units consumed.

## Features
- Accepts consumer name.
- Takes electricity units as input.
- Calculates bills using different unit slabs.
- Adds a fixed charge.
- Displays the total electricity bill.

## Technologies Used
- C++
- Conditional Statements
- Input/Output Operations

## How to Run
1. Download the C++ source code.
2. Open it in Code::Blocks or any C++ compiler.
3. Compile and run the program.
4. Enter consumer details and electricity units.
